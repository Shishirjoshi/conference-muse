Contributing
============

Thanks for your interest in contributing to this project.

Commit message guidelines
- Use conventional commits: `feat:`, `fix:`, `chore:`, `docs:`, `test:`, `perf:`.
- Keep the subject under 72 characters.
- Use the body to explain the "why" when necessary.

Pull requests
- Open a PR against `main` with a clear description of changes.
- Include tests for new features or bug fixes where possible.
- Link any related issues in the PR description.

Code style
- Run `npm run format` to format changes.
- Run `npm run lint` and `npm test` before creating a PR.
